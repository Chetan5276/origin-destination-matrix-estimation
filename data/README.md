# Data

Tracked inputs for the Sioux Falls OD pipelines.

| File | Description |
|------|-------------|
| `sioux-falls.net.xml` | SUMO network (24 zones) |
| `EstimatedODMatrix.npy` | Base 24×24 OD matrix |

Generated tensors (synthetic OD batches, turning counts, models) are written to `../outputs/` and are not committed.
